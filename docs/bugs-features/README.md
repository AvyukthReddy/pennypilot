# Bug / feature traces

One file per bug or feature, tracing it start to finish: how it was found or scoped,
what was tried, what worked, what didn't, and how it was verified. Anyone — human or AI
— should be able to read one of these cold and know exactly how to pick up where it left
off.

Naming: `YYYY-MM-DD-short-slug.md` (e.g. `2026-08-11-profile-avatar-upload.md`). Copy
[TEMPLATE.md](TEMPLATE.md) to start one. Keep it updated as you go, not just at the end —
if the AI session resets mid-task, this file is what lets the next session resume without
re-discovering everything.
